Quick guide

Ready to save Mario?

Move: ← / → or the Move button. Jump: Space / ↑. Power: X. Collect coins, avoid enemies and reach the castle flag. Use Start game to begin, and select a world to change the level theme.

Webcam gesture recognition is shown as a UI option only; it is not connected to a hand-tracking model in this frontend demo.
